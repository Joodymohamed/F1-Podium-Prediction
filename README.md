# Formula 1 Podium Prediction

Milestone 1 — ACL

Predicts whether a Formula 1 driver will finish on the podium using
only information available after qualifying and before the race.

## Dataset
Formula 1 World Championship 1950–2024 — Kaggle / Ergast

## Models
- Logistic Regression
- Gradient Boosting
- Shallow Feed-Forward Neural Network

## Split
- Train: 2003–2019
- Validation: 2020–2021
- Test: 2022–2024

## Main Test Result
Gradient Boosting:
- ROC-AUC: 0.9397
- PR-AUC: 0.7243
- F1: 0.6968
